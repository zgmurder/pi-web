警情分析助手 · 本机浏览器（0.15.59-report.2）
最低兼容目标 Chrome 109；已在官方 Chromium 109.0.5414.0 和 Chrome 155 验证，实际 Chrome 139/裁剪版 Chromium 仍需现场验收。

1. 解压到固定文件夹，后续不要删除或移动。
2. 在 Chrome 地址栏输入 chrome://extensions，打开开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 返回警情分析助手，点击浏览器工具栏的本扩展图标（可先固定到工具栏）。
5. 核对站点地址，点击“信任当前站点”。内网 HTTP 存在明文传输风险，优先使用 HTTPS。
6. 刷新网页，在已有对话的“业务配置 → 本机浏览器”点击连接；再打开扩展图标，核对会话并确认。

更新：覆盖原解压目录中的全部文件，在扩展管理页点击重新加载，再刷新助手页面。
旧信任/凭证自动迁入扩展源IndexedDB并清除旧副本；失败停止连接，可从弹窗重新检测。不建议直接降级旧包。
弹窗错误或长时间未就绪：点击“重新检测”；仍失败时在扩展管理页查看错误并重新加载。不要在chrome://extensions页面点击信任。
Chrome 109后台唤醒采用一分钟周期；休眠/节能可能延迟重连，操作超时可待网页显示在线后重试。
之后无需再次安装、填写地址、设备名或配对码；新会话需单独连接确认。
离开业务后在网页配置断开会话或撤销设备。扩展中“停止并忘记站点”可立即停止接收后续命令，但已发送操作可能完成；不会注销业务系统。
本扩展具有广泛浏览器权限，仅用于可信操作员。不要在对话中发送密码。验证码、扫码、UKey等请人工完成。
